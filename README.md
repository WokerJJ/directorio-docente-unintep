# Directorio docente UNINTEP

Interfaz web para trabajar la plantilla `PLANTILLA_DIRECTORIO.xlsx` de la Institución Universitaria de Roldanillo (UNINTEP).

- Lee y vuelve a escribir el mismo Excel, con el formato original.
- Directorio con búsqueda y filtros, ficha por docente, formulario con validación.
- Revisión de calidad de datos (cédulas, correos, fechas, sedes, niveles) con corrección automática.
- Resumen, sedes, cumpleaños y exportación a Excel, CSV y listado imprimible.

**Privacidad:** todo se procesa en el navegador. El repositorio no contiene datos de docentes y los archivos que se abren no se suben a ningún servidor.

Es un solo archivo (`index.html`), sin dependencias externas ni instalación.
